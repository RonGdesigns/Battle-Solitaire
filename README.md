# Battle Solitaire

Battle Solitaire is a mobile-first competitive solitaire game prototype.

## Current direction

- Unity 6.6 target
- Android-first, portrait orientation
- Pure C# rules and battle state separated from presentation
- Seeded solitaire deals for deterministic testing and future ranked fairness
- Local player-vs-AI prototype before online multiplayer

Development is organized by gameplay milestones so the core solitaire rules, battle systems, and presentation can be tested independently.
